台灣知名財經資訊與消費型 App 公司招募後端技術主管：直接進入事業團隊，帶領約 8–10 位 Backend、Web、iOS、Android 工程師，同時負責關鍵系統的架構決策與 AI 輔助開發的工程品質。

工作內容

主導關鍵系統架構與技術決策

  • 針對高流量、高併發及複雜商業情境進行系統建模與架構設計，評估效能、穩定性、擴展性與開發成本之間的取捨，形成團隊可執行的技術方案。

把關 AI 輔助開發的工程品質

  • Review AI Agent 或工程師提出的架構、Workflow 與關鍵實作，辨識競態條件、鎖競爭、資料一致性、效能瓶頸及不合理的系統耦合，避免開發速度提升的同時累積系統性風險。

帶領 8–10 位跨端工程師交付產品

  • 管理 Backend、Web、iOS、Android 工程師，依產品與技術目標建立優先順序、拆解複雜問題並推進執行，確保跨端開發能有效協作並完成交付。

處理高複雜度的系統與效能問題

  • 針對一般開發流程難以解決的效能、併發、資料存取與系統穩定性議題進行分析，找出根因並帶領團隊完成改善，而不只是處理表層異常。

建立並持續改善工程標準

  • 從 Code Review、架構設計、技術債管理到 AI 輔助開發方式，建立團隊可遵循的工程原則，降低系統複雜度與長期維護成本。

培養工程團隊的技術判斷能力

  • 透過技術討論、Design Review、Code Review 與日常 Coaching，協助不同領域與資歷的工程師提升問題拆解、架構思考與技術決策能力。

與產品及事業團隊共同進行技術取捨

  • 將複雜的架構限制、技術風險與投入成本轉化為非技術角色可以理解的決策資訊，協助團隊在商業速度與工程品質之間做出合理選擇。

應徵條件

必要條件
  • 具備正式工程團隊管理經驗，曾直接帶領至少 5 人以上工程團隊（涵蓋 Backend、Web、iOS、Android 的工程師）
  • 具備高流量、高併發或大型 Production 系統實戰經驗
  • 目前仍具備實際做架構判斷與 Technical Review 的能力
  • 已實際使用 LLM／Coding Agent 輔助軟體開發工作
加分條件
  • 具備金融、FinTech、大型消費者產品或其他高流量服務的系統開發經驗

為什麼選擇這個機會

技術與管理並重

既要對架構品質負責，也要讓跨端工程師有效協作、持續成長。

規模夠大的消費型產品

用人單位經營多款投資理財與生活型 App，用戶量大，做出來的東西會直接影響大量真實使用者。
