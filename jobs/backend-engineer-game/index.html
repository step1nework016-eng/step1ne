工作內容

系統開發與維護

  • 參與企業內部系統的開發、維護與功能優化
  • 使用 C#、.NET／.NET Framework 進行應用程式與 API 開發
  • 使用 Microsoft SQL Server（MSSQL）進行資料查詢、資料處理及效能優化
  • 協助分析系統問題，執行程式除錯、測試及異常排除

團隊協作與 AI 輔助開發

  • 參與需求討論、技術設計、程式碼審查（Code Review）及團隊協作
  • 運用 AI 輔助開發工具進行程式撰寫、除錯、重構及技術研究，提升開發效率與品質
  • 撰寫與維護必要的技術文件，持續改善程式碼品質、可維護性及系統穩定性

加入後會持續累積的能力

  • 企業系統開發：深入理解企業內部系統、資料庫設計與系統整合
  • 現代化技術：參與既有系統優化、技術升級與現代化開發實務
  • AI 輔助工程：探索 AI Coding Agent、自動化開發與新型態軟體開發流程
  • 軟體工程實踐：透過 Code Review、CI/CD 與團隊協作提升程式品質

應徵條件

必要條件
  • 2 年以上軟體開發相關工作經驗
  • 熟悉 C#，具備 .NET 或 .NET Framework 實際開發經驗
  • 熟悉 MSSQL，能撰寫基本 SQL、JOIN、Stored Procedure，並具備資料庫操作能力
  • 具備基本物件導向程式設計（OOP）及程式設計觀念
  • 具備 Git 版本控制基礎，了解基本分支管理與團隊開發流程
  • 具備 AI 輔助程式開發經驗，曾使用 ChatGPT、GitHub Copilot、Cursor、Claude Code、Codex 或其他同類工具，協助完成實際開發或技術問題排除
加分條件
  • 熟悉 ASP.NET Core、ASP.NET MVC 或 Web API 開發
  • 具備 RESTful API 設計或系統整合經驗
  • 了解 SQL 效能優化、索引設計或資料庫效能分析
  • 具備 GitLab CI/CD、自動化測試或持續整合經驗
  • 曾接觸 Docker、Kubernetes 或 AWS、GCP、OCI 等雲端服務
  • 具備使用 AI Coding Agent 協助功能開發、程式重構或自動化測試的經驗
  • 曾主動研究 AI 開發工具、Agent Workflow、MCP 或其他提升軟體開發效率的技術
  • 具有個人技術專案、GitHub 作品或持續學習的實際成果
