數據分析師 Data Analyst（BigQuery・SQL）

這個缺在一間上市集團的數據團隊，需求 1 名。團隊串接旗下多個事業體的數據，把它變成口徑一致、可信賴、可直接用於決策的數據產品；你會是「可分析層」的主要建造者，你定義的指標與資料集，會成為各事業體看板、深度分析與 AI 自助查詢的基礎。

工作內容

建資料集、定指標

  • 建置分析資料集與指標模型（主責）：在 BigQuery（及導入中的 Lakehouse 平台）把原始資料整理成可複用的 Data Mart，從需求釐清、建模、驗證到上線維護全程負責，並作為資料工程與商業應用之間的橋樑
  • 定義指標與維護數據字典（主責）：定義集團核心指標（跨服務活躍、會員歸戶、留存等），與各事業體對齊計算口徑與商業邏輯

把關品質、推廣使用

  • 把關數據品質：與資料工程團隊協作，驗收進入中台的資料，建立異常偵測機制，並追蹤問題到源頭解決
  • 推廣數據驅動文化：擔任各事業體的數據顧問與窗口，設計與維護商業看板，協助 AI/BI 自助查詢工具的推廣（包含語意設定、回答品質優化與使用者培訓）
  • 專題分析與治理協作：運用自建資料集，與分群、CDP 同事協作回應營運議題；依個資分級與權限規範使用資料

應徵條件

必要條件
  • 3 年以上數據分析、Analytics Engineering 或商業分析相關經驗
  • 具備將 AI 工具（如 Claude、Gemini 等）應用於日常工作流程的實戰經驗，能有效提升工作效率與專案品質
  • 進階 SQL 與雲端資料倉儲實戰經驗（BigQuery 或同級），能處理大規模資料並具查詢成本意識；具 Python 基礎資料處理能力
  • 數據建模實務：設計過分析資料集或維度模型（Star Schema），且實際上線、被他人長期使用
  • 能從模糊的業務需求中定義指標與驗證方式，並與不同單位把定義談清楚
  • 對數據正確性有高標準：交付前會自行驗證與交叉檢核
  • BI 工具（Looker Studio／Tableau／Power BI 擇一）從需求訪談到上線的完整經驗，能獨立界定範圍、安排時程並交付
  • 能把分析結果與指標限制，清楚說明給非技術背景的主管與營運團隊；樂於教別人使用數據
加分條件
  • dbt、Git 等 SQL 版本控制與 Modern Data Stack 經驗
  • Lakehouse／資料治理平台（Databricks、Snowflake 等）或語意層（Semantic Layer）經驗
  • 善用 AI／LLM 工具加速分析與開發，或有 AI/BI 導入經驗
  • 事件追蹤與埋點設計（GA4、GTM）
  • 會員經營、CDP、分群貼標或 A/B Testing 實務
  • 媒體、電商或會員制服務產業經驗；對個資法／GDPR 有基本概念
  • 專精於統計、應數與資管領域，能獨立進行數據分析與商業解讀

為什麼選擇這個機會

你定義的指標，別人每天在用
