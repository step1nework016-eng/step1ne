數據專案 PM（集團總部・台北內湖）

這個缺在一間上市集團的總部（台北內湖），需求 1 名，週一至週五上班，月薪 50,000–55,000 元。你會扮演數據專案「落地的推動者」：把需求整理成可開工的規格，協調分析師、資料工程與各事業體窗口，一路追到按時交付。

工作內容

需求與規格

  • 需求梳理（主責）：把需求整理成可開工的需求文件（目的、資料範圍、產出、驗收方式），並與需求方確認優先順序
  • 資料規格整理（主責）：與分析師、工程團隊確認資料來源、欄位定義與觸發時機，產出精簡的規格表，作為開發與驗收的依據

協調與進度

  • 跨單位協調：主持需求討論與進度會議，釐清各方分工與時程，追蹤待辦到結案；遇到卡點時先行協調，需拍板的事項整理給主管
  • 進度與風險管理：維護專案看板（Jira／Confluence），定期回報專案狀態、風險與資源需求

文件與結案

  • 文件與知識管理：集中管理會議紀錄、決議與規格版本，讓專案成果可被團隊與後進者接手
  • 專案結案與匯報：整理交付成果與效益數據，協助產出向上匯報用的摘要

應徵條件

必要條件
  • 2 年以上 PM、專案協調或系統分析相關經驗，帶過至少一個跨部門專案從需求到上線
  • 溝通協調是你的強項：能把技術與業務兩邊的話翻譯成對方聽得懂的版本，會主持會議並把結論寫下來、追到底
  • 具備基礎系統與資料架構概念：理解從事件埋點、系統 log、資料倉儲到報表與 CDP 的端到端資料流，熟悉 API 介接、事件定義與跨系統 ID mapping；能閱讀資料字典與 schema，與 RD 討論欄位定義、資料型別與觸發時機
  • 文件能力：需求文件、規格表、會議紀錄寫得清楚、精簡，有版本管理習慣
  • 使用過 Jira、Confluence、Notion 或同類工具管理專案
  • 具備將 AI 工具（如 Claude、Gemini 等）應用於日常工作流程的經驗，能用來加速文件整理與需求梳理
  • 中文溝通流利，能閱讀英文技術文件
加分條件
  • 會基本 SQL，能自行查資料驗證需求與交付
  • 用過 GA4／GTM、CDP（Infobip、Braze 等）或任一資料平台（BigQuery、Databricks）
  • 接觸過資料治理或個資合規流程（資料分級、授權、委託處理）
  • 做過資料產品、BI 報表或數據平台相關的 PM 工作
  • 媒體、電商或會員制的 C 端產業經驗
