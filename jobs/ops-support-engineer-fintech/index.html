派遣職缺2年以上經驗金融科技

維運支援工程師電子支付系統

電子支付公司尋找維運支援工程師，負責系統狀態監控、異常分析與版本管理，並執行弱點掃描以確保系統安全。適合具備維運經驗、想切入金融科技領域的人。

工作內容

系統維運與監控

  • 負責 Log 查詢、系統狀態監控與問題回報
  • 分析與回應系統異常，主導問題分析報告

版本與程式碼管理

  • 負責系統版本管理與同步，確保更新符合計畫與流程
  • 進行程式碼版本控管，確保開發與維運流程一致

資安檢核

  • 執行弱點掃描分析，並產出報告與建議

跨單位協作

  • 與 RD、QA、Infra、資安、PM 等內外部團隊合作確保維運順暢

應徵條件

必要條件
  • 2 年以上系統維運經驗
  • 具備系統監控與故障排除經驗，熟悉 Log 查詢與分析工具（如 ELK）
  • 熟悉版本控管工具（Git），並理解 CI/CD 流程
  • 具備基本資安概念，熟悉弱點掃描與風險評估（如 Fortify、OWASP）
  • 具備基本 C# / .NET / SQL 知識，能閱讀並理解程式碼
加分條件
  • 有電子支付或金融系統相關經驗
  • 具備跨團隊溝通協調能力
  • 熟悉資安法規與稽核流程
