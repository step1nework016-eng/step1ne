工作內容

端到端打造 AI Agent 的核心能力

  • 從洞察商家與買家的真實需求開始
  • 一路到設計、實作
  • 以及上線後的成效驗證

以 AI 工具高速交付

  • 買家的視角

讓成果可被衡量

  • 依據對照組實際呈現的結果反覆迭代，不是依據感覺

應徵條件

必要條件
  • Claude Code 是你主要的開發方式——不是偶爾用來輔助，而是你把想法變成可用產品的預設工具
  • 實際打造或優化過 AI Agent（sales agent、customer success agent，或任何自主型 agent 都算）
  • 熟悉 prompt engineering、RAG、agent 架構、tool use、multi-agent 協作中的一項或多項
  • 有把事情做成的實際紀錄——不一定是寫程式，把一門生意做起來、把社群經營到高度活躍、設計出一套讓事情順暢運作的系統都算
  • 表達精準：設計 agent 本質上是用語言思考，指令模糊 agent 就會模糊
  • 渴望真正的 Ownership，想把這個產品當成自己的事業在打造

為什麼選擇這個機會

不是填空題

沒有現成的 agent 框架等著你填內容。從觀察真實買家行為到上線驗證，整條路徑由你自己走完。

用數字驗證，不是用感覺

成效看對照組實際呈現的結果。做得好不好有答案，不是誰講話大聲。

Ownership 是真的

團隊要找的是把產品當自己事業在做的人，不是執行角色。

常見問題

待遇大概多少？+

業主公告是待遇面議（經常性薪資達 4 萬元或以上），實際依個人資歷與面談結果核定。我們不會在職缺頁上寫一個沒經過確認的數字。

一定要會寫程式嗎？+

必備條件要求 Claude Code 是你主要的開發方式，並且實際做過 AI Agent。但「把事情做成的紀錄」不限於寫程式——經營過社群、做起一門生意、設計過一套讓事情順暢運作的系統都算。

是哪一家公司？+

業主希望在初步接觸階段先不公開公司名稱。通過初步評估後，顧問會在聯繫時完整說明公司背景、產品與團隊狀況。
