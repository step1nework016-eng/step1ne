  • 有大型資料平台／Big Data Engineering 實戰經驗

常見問題

面試流程？+

全程線上：兩關職能面試（約 1.5 小時、1 小時）＋HR 價值觀面談約 1 小時＋與技術主管約 30 分鐘。

只會 Python 可以嗎？+

Scala 實際開發經驗是必要條件。

為什麼一直提到 AI？+

用人單位很重視「實際把生成式 AI／Coding Agent 用進工作流程」的經驗，面試也會問。建議準備一個講得出細節的實際例子。

是哪一家公司？+

用人單位希望在初步接觸階段先不公開公司名稱。通過初步評估後，顧問會在聯繫時完整說明公司背景、產品與團隊狀況。
