工作內容

建置消費 Raw Data 的資料基礎

  • 從 MongoDB 等 Source System 進行資料擷取、清理、轉換與儲存，建立穩定、可追蹤且可擴展的 Raw Data Pipeline，讓下游分析與資料應用能取得可信賴的資料。

設計與維護 Hybrid Data Pipeline

  • 依資料量、處理時效與使用情境，規劃 Cloud 與 On-premise 之間的資料流、運算與儲存方式，確保大量消費資料能穩定流通與處理。

建立可支援大量資料的 Data Pipeline 與資料架構

  • 針對 Batch 與不同時效需求設計資料處理流程、資料模型與查詢結構，在效能、穩定性、成本與維護性之間做出合理的技術取捨。

提升資料品質與 Pipeline 穩定性

  • 建立資料驗證、異常監控、錯誤處理與可觀測性機制，快速定位資料缺漏、延遲或 Pipeline Failure 的根因，確保下游使用者取得正確且穩定的資料。

與分析、產品及相關團隊定義資料需求

  • 理解分析與商業應用真正需要的資料粒度、更新頻率與使用方式，將需求轉化為可落地的 Data Pipeline 與資料架構，而非單純依規格搬運資料。

持續改善資料工程架構與開發流程

  • 辨識既有 Pipeline、Storage 或 Data Processing 中的效能與維護問題，逐步改善資料處理效率、工程品質與自動化程度。

支援近即時資料應用的工程需求

  • 依推薦、廣告、推播等資料使用情境，參與 Streaming / Near Real-time Pipeline 的設計與建置，縮短資料從 Source 到下游應用可使用的時間。

應徵條件

加分條件

  • 曾支援推薦系統、廣告、CRM／推播等時效性較高的資料應用，理解從事件產生、資料處理到下游 Serving 的完整資料流。
  • 電商、零售、消費產業的 Data Engineering 經驗
