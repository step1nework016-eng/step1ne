資深測試產品專員（遊戲・台北內湖）人力派遣・全職｜月薪 40–45K｜週一至週五・週休二日｜功能測試／Bug tracking／測試報告書撰寫

職稱雖寫「資深」，但用人單位這次沒有開年資門檻——做過功能測試、Bug 追蹤到結案、能自己寫測試計畫與測試報告書，就值得投。這個缺在一家上市集團的台北內湖辦公室，做的是遊戲產品上線前後的測試把關：把測試案例寫出來並維護好，依排程執行使用者測試、功能測試與壓力測試，抓到問題就記錄重現步驟、追蹤到修好為止，再把結果整理成測試報告書給產品與開發部。工作不只是點點看——測試計畫與報告書要自己寫，跨部門的問題也要你主動去釐清。班是固定的週一至週五，需求 1 名。派遣期間你與 Step1ne（德仁管理顧問有限公司）簽訂正式勞動契約，日常工作在用人單位的內湖辦公室進行。

工作內容

測試案例與測試計畫

  • 依產品規格編寫遊戲測試案例，並隨版本更新維護既有案例
  • 規劃測試範圍與排程，撰寫測試計畫

執行測試

  • 依排程執行各項功能的定期測試，包含使用者測試、功能測試與壓力測試
  • 版本更新後進行回歸測試，確認既有功能沒有被改壞

問題追蹤與報告

  • 記錄問題的重現步驟與影響範圍，分級後進入 Bug 追蹤流程
  • 追蹤問題修復進度直到結案並完成驗證
  • 彙整測試結果，撰寫測試報告書並提交產品部與開發部

跨部門協調

  • 協助產品部與開發部釐清問題成因與規格認定上的落差
  • 與各部門（含產品部、開發主管）就測試排程與修復優先序溝通協調

應徵條件

必要條件
  • 具功能測試（function test）實務經驗
  • 熟悉問題追蹤處理（Bug tracking）：能完整記錄、分級並追蹤到結案
  • 具軟體整合測試經驗
  • 能獨立撰寫測試計畫與測試報告書
  • 能與產品、開發等不同角色溝通，把問題講清楚並推動處理
  • 可在台北內湖辦公室週一至週五上班
加分條件
  • 具 Source Code 層級的產品測試經驗（可讀程式碼協助判斷問題成因）
  • 平常有在玩日系遊戲，熟悉這類產品的玩法與使用者習慣
  • 有撰寫測試案例管理或 Bug 追蹤系統使用經驗

為什麼選擇這個機會

測試流程是完整的，不是只叫你點一點

測試案例自己寫、測試計畫自己排、測試報告書自己交。做完一輪你手上留下的是可以拿出去講的測試文件與流程經驗，而不是只有「我測過很多版本」。

直接對接產品部與開發部

問題不是丟進表單就沒下文，你要跟產品與開發主管把成因和規格認定講清楚、把優先序談出來。想往測試主管或 QA 流程規劃走，這段經驗是必要的。

常見問題

派遣工作的權益跟正職一樣嗎？+

派遣期間你與 Step1ne（德仁管理顧問有限公司）簽訂正式勞動契約，工資、勞健保、勞退提繳、特別休假、加班費與職業災害補償等權益，一律依勞動基準法及相關法令辦理，與一般受僱者相同；資遣與退休也同樣適用勞基法規定。日常工作在用人單位辦公室進行、由現場主管安排任務，但雇主責任在 Step1ne。

月薪 40–45K，我實際會拿到多少？+

公開頁面寫的是總額區間：月薪 40,000 – 45,000 元，依經驗核定。薪資怎麼組成，顧問在電話初談時會一次說清楚，你可以在那時候直接問到底。

職稱寫「資深」，要幾年經驗才能投？+

用人單位這次沒有給年資門檻，所以我們不會在頁面上寫一個沒確認的數字。條件看的是你實際做過什麼：功能測試、Bug 追蹤到結案、軟體整合測試，以及能不能自己把測試計畫與測試報告書寫出來。這四件事你都做過，就值得投，年資的部分顧問會替你向用人單位確認。

一定要會寫程式嗎？+

不用。必要條件是功能測試、整合測試與問題追蹤這類實務經驗。「Source Code 產品測試經驗」是加分條件，有的話在應徵時說明你用程式碼層的方式找出過什麼問題。

沒有在玩日系遊戲可以投嗎？+

可以。「喜愛日系遊戲」是加分條件不是門檻。不過這個職務每天都在測遊戲產品，對遊戲本身有感覺的人通常比較容易抓到玩家會卡住的地方，有的話請在應徵時提。

面談流程是什麼？會不會跟 AI 面談？+

會。初步面談由 AI 進行，用文字或語音對談，確認你的經驗與這個職缺的條件對不對得上；通過後由顧問安排用人單位面試。AI 初談的時間你可以自己選，不用請假配合。

上班時間幾點到幾點？要配合版本更新加班嗎？+

用人單位這次只確認了週一至週五、週休二日，具體上下班時段還沒給我們，是否需要配合版更或上線時段調整也沒有說明，所以我們不會在頁面上寫沒確認的事。顧問會在初談前先問清楚再告訴你。

這個派遣缺會做多久？有機會轉正職嗎？+

用人單位目前沒有給我們約期長度與轉正的承諾，所以頁面上不會寫。你在意的話，面談時我們會直接替你問，並把用人單位的回覆原話轉給你。
