全民獵才：推薦職缺給朋友，媒合成功到職拿獎金

直接答案：全民獵才是掛在 Step1ne LINE 官方帳號上的免費小程式（LINE Mini App），加好友即可開啟，免下載、免安裝。把適合的職缺分享給朋友，媒合成功並到職、且在職滿保證期後，即可領取推薦獎金。不必是專業獵頭，任何人都能用。

全民獵才是什麼？

全民獵才是 Step1ne 推出、掛在 LINE 官方帳號上的小程式（LINE Mini App）。加入 Step1ne LINE 好友後即可直接開啟使用，不需要另外下載安裝任何 App。你可以在裡面瀏覽職缺、把適合的職缺分享給朋友，並追蹤推薦的媒合進度。

推薦職缺有獎金嗎？獎金怎麼算？金額確認中

有。推薦獎金依職缺層級與薪資條件分級計算，不是所有職缺齊頭式的固定金額。目前正式的獎金級距金額仍在確認中，實際金額請以顧問透過 LINE 回覆的內容為準。

介紹朋友工作，多久才能拿到獎金？天數確認中

你推薦的朋友到職後，需要在職滿一段保證期，獎金才會發放，避免短期到職又離職的情況。確切的保證期天數仍在確認中，實際規定請以顧問透過 LINE 回覆的內容為準。

一定要是專業獵頭才能推薦人才拿獎金嗎？

不用。全民獵才開放給所有人使用，不需要獵頭背景或招募經驗。只要加入 LINE 好友，看到適合的職缺就能分享給身邊在找工作的朋友，媒合成功即有機會領取推薦獎金。

全民獵才要怎麼開始使用？

  1. 加入 Step1ne LINE 官方帳號好友
  2. 在對話選單中開啟「全民獵才」小程式，免下載安裝
  3. 瀏覽目前開放的職缺，把適合的職缺分享給朋友
  4. 朋友透過你分享的連結應徵、進入媒合流程
  5. 媒合成功並到職、在職滿保證期後，領取推薦獎金

全民獵才跟一般找工作 App 有什麼不同？

全民獵才不是要另外下載的獨立 App，而是直接掛在 LINE 官方帳號上的小程式，加好友就能用，手機不用多裝一個 App。它的核心也不是「自己求職」，而是「幫朋友找到工作、自己拿獎金」——你不必是求職者本人，也能透過推薦職缺參與媒合並獲得回饋。
