AI Agent DesignerAIスタートアップ・正社員・南港ソフトウェアパーク

「店舗向けAI営業担当」を開発中のスタートアップで、サービス対象は米国のEC事業者です——あなたの一つひとつの設計判断が、米国の事業者のコンバージョン率に直接影響します。多くのAIエージェントの成果はデモの印象で評価されますが、このチームは違います——対照群の実際の数字で検証します。この求人には、穴埋めするだけの既成のエージェントフレームワークはありません。実際の購買者行動の観察、リサーチ、プロンプト設計、実装、リリース後の効果検証まで、すべてをあなた自身が一貫して担います。

仕事内容

AI Agentをエンドツーエンドで構築するコア能力

  • 事業者と購入者の本当のニーズを見極めるところから始める
  • そして設計、実装まで
  • そしてリリース後の効果検証

AIツールでスピーディーに納品

  • Claude Codeを多用
  • 複雑な agent ロジックを数時間で使えるプロダクトに変える

複数の視点から体験を磨き上げる

  • 事業者の視点
  • バイヤーの視点
  • ビジネス成果の視点――同じデザイン上の判断でも、この3つの視点ではしばしば3つの異なる正解があります

成果を測定できるようにする

  • 感覚ではなく、対照群で実際に出た結果に基づいて繰り返し改善

応募条件

必須条件
  • Claude Codeがあなたの主な開発手段です——たまに補助として使うのではなく、アイデアを使えるプロダクトに変えるための標準ツールです
  • AIエージェント（sales agent、customer success agent、その他あらゆる自律型エージェントを含む）を実際に構築または改善した経験
  • prompt engineering、RAG、agent アーキテクチャ、tool use、multi-agent 連携のうち1つ以上に精通している方
  • 物事を実際にやり遂げた実績——プログラミングに限らず、事業を立ち上げた、コミュニティを非常に活発に育てた、物事が円滑に回る仕組みを設計した、などもすべて含みます
  • 的確に伝える力：エージェントの設計は本質的に言葉で考えること。指示があいまいなら、エージェントもあいまいになります
  • 真のオーナーシップを求め、このプロダクトを自分の事業としてつくり上げたい方

このチャンスを選ぶ理由

穴埋め問題ではない

中身を埋めるだけの既成のエージェントフレームワークはありません。実際の購入者の行動観察から本番での検証まで、道のり全体をあなた自身で歩みます。

感覚ではなく、数字で検証する

成果は対照群に実際に表れた結果で判断します。うまくいったかどうかには答えがあり、声の大きさで決まるものではありません。

Ownership は本物です

チームが探しているのは、プロダクトを自分の事業として取り組む人で、実行役ではありません。

よくある質問

待遇はどれくらいですか？+

採用企業の公表は給与応相談（経常的給与4万台湾ドル以上）で、実際の金額は個人の経歴と面接結果により決定されます。確認できていない数字を求人ページに書くことはありません。

プログラミングができないとだめですか？+

必須条件として、Claude Code が主な開発手段であり、実際に AI Agent を作った経験が求められます。ただし「物事をやり遂げた実績」はプログラミングに限りません。コミュニティの運営、ビジネスの立ち上げ、物事を円滑に回す仕組みの設計もすべて含まれます。

どの会社ですか？+

採用企業は、初期の接触段階では社名を公開しないことを希望しています。初回の評価を通過した後、コンサルタントが連絡する際に会社の背景、製品、チームの状況を詳しくご説明します。
