仕事内容

システム開発と保守

  • 社内システムの開発、保守、機能改善に携わります
  • C#、.NET／.NET Frameworkを使ったアプリケーションとAPIの開発
  • Microsoft SQL Server（MSSQL）を使ったデータ照会、データ処理、パフォーマンス最適化
  • システムの問題分析をサポートし、デバッグ、テスト、障害対応を行います

チームでの協働とAIを活用した開発

  • 要件の検討、技術設計、コードレビュー、チームでの共同作業に参加します
  • AI支援開発ツールを活用してコーディング、デバッグ、リファクタリング、技術調査を行い、開発の効率と品質を向上
  • 必要な技術文書を作成・維持し、コード品質、保守性、システムの安定性を継続的に改善します

入社後に積み上げていけるスキル

  • 企業システム開発：社内システム、データベース設計、システム連携を深く理解していること
  • モダナイゼーション：既存システムの最適化、技術のアップグレード、モダンな開発実務に携わります
  • AI支援エンジニアリング：AI Coding Agent、開発の自動化、新しいソフトウェア開発プロセスの探求
  • ソフトウェアエンジニアリングの実践：Code Review、CI/CD、チーム連携を通じてコード品質を向上

応募条件

必須条件
  • ソフトウェア開発関連の業務経験2年以上
  • C#に精通し、.NETまたは.NET Frameworkでの実務開発経験があること
  • MSSQLに精通し、基本的なSQL、JOIN、Stored Procedureを記述でき、データベースを操作できること
  • オブジェクト指向プログラミング（OOP）とプログラミングの基本的な考え方を理解している方
  • Gitによるバージョン管理の基礎知識があり、基本的なブランチ管理とチーム開発の流れを理解している方
  • ChatGPT、GitHub Copilot、Cursor、Claude Code、Codex などのツールを使い、AIを活用したプログラム開発や技術的な問題の解決を実務で行った経験
歓迎条件
  • ASP.NET Core、ASP.NET MVC、またはWeb APIの開発に精通していること
  • RESTful APIの設計またはシステム連携の経験
  • SQLのパフォーマンス最適化、インデックス設計、またはデータベースのパフォーマンス分析の知識
  • GitLab CI/CD、自動テスト、継続的インテグレーションの経験
  • Docker、Kubernetes、またはAWS、GCP、OCIなどのクラウドサービスに触れた経験
  • AIコーディングエージェントを活用した機能開発、リファクタリング、自動テストの経験
  • AI開発ツール、Agent Workflow、MCPなど、ソフトウェア開発の効率を高める技術を自ら研究した経験
  • 個人の技術プロジェクト、GitHubでの制作物、継続的な学習の具体的な成果

このチャンスを選ぶ理由

AI支援開発はこのポジションの日常業務です

派遣先はAIを活用した開発を中核の重点と位置づけており、単なるおまけではありません。すでにAIツールでコーディング、デバッグ、リファクタリングをしている方なら、その経験を実際に活かせる環境です。

仕事をこなすだけでなく、仲間と一緒に成長できます

業務にはコードレビューとチームでの協働が含まれます。配属先の部門は、設計、開発、問題解決を自律的にこなせるソフトウェアエンジニアへ段階的に成長していくことを期待しています。

派遣期間中は、Step1ne（德仁管理顧問有限公司）と正式な労働契約を結びます。賃金、労働保険・健康保険、年次有給休暇は労働基準法に基づきます。
