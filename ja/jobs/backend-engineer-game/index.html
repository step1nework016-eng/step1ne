仕事内容

Web サイトと EC サイトの開発

  • ゲーム製品の公式サイトの開発・保守
  • ゲーム製品のWebストア機能の開発・保守
  • Webシステムのアーキテクチャ分析と機能開発

APIとデータ処理

  • ゲームプロダクトとサードパーティプラットフォームのAPI連携の構築・保守
  • Web APIの開発・運用とバージョン管理
  • データベース操作、パフォーマンスチューニング、データ処理

運用サポート

  • 異常の切り分けとシステム問題の分析をサポート
  • 開発規約に従い、チームと協力してプロジェクトを完成させる

応募条件

必須条件
  • .NET Core / .NET Frameworkでのシステム開発経験
  • MSSQLデータベースの操作に精通
  • T-SQL と Stored Procedure の作成・保守に精通している方
  • WebService / WebAPIのアーキテクチャと開発に精通
歓迎条件

以下は歓迎条件です。いずれか1つに当てはまれば十分で、すべてを満たす必要はありません。

  • Redis / RabbitMQ / Kafkaなどのキャッシュやメッセージキューの活用経験
  • Kubernetes (K8S) / GKE のクラウド利用経験
  • 大規模トラフィックのサイトや高同時接続システムの開発経験
  • システムのパフォーマンス最適化またはSQLのパフォーマンスチューニングの経験
  • マイクロサービス（Microservices）アーキテクチャ設計に精通していること
  • OAuth 2.0 / OpenID Connect / JWT認証の仕組みに精通
  • Web サイトの開発とデプロイの経験
  • JavaScript、jQuery、AJAX、JSON連携に精通している方
  • CI/CDフローの使用経験
  • セキュリティの概念を持ち、安全な開発の規範を守れる方

このチャンスを選ぶ理由

上場ゲームグループで、基幹システム開発に携わるチャンス

配属先は台湾で上場しているゲーム業界グループの製品開発／IT開発部門です。今回は公式サイト兼オンラインショップのバックエンドチーム拡充に伴う募集で、グループのゲーム公式サイトとショップシステムの開発・運用に直接携われます。

給与は能力により応相談、柔軟に対応

雇用主は定型の給与レンジを設けておらず、実際の待遇は技術力と経験に応じて面接後に決定されます。技術がしっかりしている方は、より競争力のある待遇を得られる可能性があります。

派遣期間中の権利は労働基準法に準じ、正社員と変わりません

派遣期間中は Step1ne があなたと正式な労働契約を結び、給与、労工保険・全民健康保険、年次有給休暇などの権利はすべて労働基準法に基づき、一般の被雇用者と同じです。

急募のため優先的に面接を設定し、就職活動をスピードアップ

この求人は急募のため、履歴書送付後に優先的に面接を設定します。より早く選考に進み、より早く結果を知ることができます。

コンサルタントが面接のポイントを一から説明し、一緒に準備します

一次面接と二次面接の2段階があります。Step1neのコンサルタントが面接の前に、出題パートを含む面接のポイントと注意事項をご説明し、自信を持って臨めるようサポートします。

よくある質問

この求人は派遣ですが、給与や保険の保障は手薄になりませんか？+

いいえ。派遣期間中はStep1neがあなたと正式な労働契約を結び、給与、労働保険・健康保険、年次有給休暇などの権利はすべて労働基準法に基づいて扱われ、一般の雇用者と同じです。

普段はStep1neと配属先のどちらで働くのですか？+

日常業務は派遣先（上場・店頭公開のゲームグループ）の現場で行い、実際の業務内容は現場の責任者が割り当てます。

面接は何回ありますか？+

一次選考と二次選考の2段階があり、面接の手配前に Step1ne のコンサルタントが面接のポイントと注意点をご説明します。

この求人には試験があると聞きましたが、どんな内容ですか？+

この求人には筆記試験・課題があります。詳しい出題形式と解答時間はまだ確定していないため、面接前にコンサルタントからご説明します。

Step1ne はどんなコンサルティング会社ですか？+

Step1neは德仁管理顧問有限公司のブランドで、台北市政府発行の就業服務許可証（北市就服字第0363号）を保有し、エグゼクティブサーチ、正社員採用、人材派遣サービスに特化しています。
