仕事内容

コンシューマー向けRaw Dataのデータ基盤構築

  • MongoDBなどのSource Systemからデータを抽出・クレンジング・変換・保存し、安定的で追跡可能かつ拡張性のあるRaw Data Pipelineを構築して、下流の分析やデータ活用が信頼できるデータを得られるようにします。

Hybrid Data Pipelineの設計・保守

  • データ量、処理の即時性、利用シーンに応じて、Cloud と On-premise 間のデータフロー、演算、ストレージの方式を設計し、大量の消費データが安定して流通・処理されるようにします。

大量データに対応できる Data Pipeline とデータアーキテクチャを構築します

  • Batchやさまざまな鮮度要件に合わせてデータ処理フロー、データモデル、クエリ構造を設計し、パフォーマンス、安定性、コスト、保守性の間で合理的な技術的トレードオフを判断できること。

データ品質とPipelineの安定性を向上

  • データ検証、異常監視、エラー処理とオブザーバビリティの仕組みを構築し、データの欠落・遅延や Pipeline Failure の根本原因をすばやく特定して、下流の利用者が正確で安定したデータを得られるようにする。

分析、プロダクト、関連チームとデータ要件を定義する

  • 分析やビジネス活用で本当に必要なデータの粒度、更新頻度、使い方を理解し、要件を実装可能なData Pipelineとデータアーキテクチャに落とし込みます。仕様どおりにデータを運ぶだけの仕事ではありません。

データエンジニアリング基盤と開発プロセスの継続的な改善

  • 既存のPipeline、Storage、Data Processingにおけるパフォーマンスや保守上の課題を特定し、データ処理の効率、エンジニアリング品質、自動化の度合いを段階的に改善する。

ニアリアルタイムのデータ活用に向けたエンジニアリングニーズを支援

  • レコメンド、広告、プッシュ通知などのデータ活用シーンに合わせて、Streaming / Near Real-time Pipelineの設計・構築に参加し、データがSourceから下流のアプリケーションで使えるようになるまでの時間を短縮します。

  • Cloud Data Engineeringの実務経験

歓迎条件

  • レコメンドシステム、広告、CRM／プッシュ通知など鮮度が求められるデータ活用を支援した経験があり、イベント発生からデータ処理、下流のServingまでの一連のデータフローを理解している方。
  • EC、小売、消費財業界でのData Engineering経験

ゼロからデータ基盤を築く

中心となるミッションはRaw Dataを使えるデータ基盤に変えることで、SourceからServingまでをあなたが考えます。
