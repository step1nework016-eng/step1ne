  • システムおよびサービスの異常分析、障害対応、問題の追跡と改善
  • 部門のオンコール当番制に従い、業務時間外の緊急システム障害に対応

連携と継続的な改善

  • 部門横断の運用ニーズに対応し、開発、テスト、運営の各チームと連携
  • 運用プロセスの改善、自動化、システム安定性の向上に継続して取り組みます

業務範囲はサーバー、製品のデプロイ、データベースの日常管理まで及びます。一部分だけを担当するのではなく、運用保守の経験を幅広く積めます。

派遣期間中は、Step1ne（德仁管理顧問有限公司）と正式な労働契約を結びます。賃金、労働保険・健康保険、労働者退職金の積立、年次有給休暇、残業代、労災補償などの権利は、すべて労働基準法および関連法令に基づき、一般の被雇用者と同じ扱いです。日々の業務は派遣先の上司が割り当てますが、雇用主としての責任はStep1neが負います。労働条件についてご不明な点があれば、担当コンサルタントに直接ご相談いただけます。
