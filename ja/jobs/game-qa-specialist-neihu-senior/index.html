シニアテストプロダクトスペシャリスト（ゲーム・台北 内湖）人材派遣・フルタイム｜月給 40–45K｜月曜〜金曜・完全週休2日制｜機能テスト／Bug tracking／テスト報告書作成

職名には「シニア」とありますが、今回の配属先では経験年数の条件を設けていません。機能テストを行い、バグを完了まで追跡し、テスト計画書とテスト報告書を自分で書いた経験があれば、ぜひご応募ください。勤務地は上場グループの台北・内湖オフィスで、ゲーム製品のリリース前後の品質チェックを担当します。テストケースを作成・維持し、スケジュールに沿ってユーザーテスト、機能テスト、負荷テストを実施。問題を見つけたら再現手順を記録し、修正されるまで追跡したうえで、結果をテスト報告書にまとめてプロダクト部門と開発部門に提出します。ただ触って確かめるだけの仕事ではありません。テスト計画書と報告書は自分で書き、部門をまたぐ問題も自ら進んで切り分けていただきます。勤務は月曜〜金曜の固定、募集人数は 1 名です。派遣期間中は Step1ne（德仁管理顧問有限公司）と正式な労働契約を結び、日々の業務は配属先の内湖オフィスで行います。

仕事内容

テストケースとテスト計画

  • 製品仕様に基づいてゲームのテストケースを作成し、バージョン更新に合わせて既存ケースを保守
  • テスト範囲とスケジュールを計画し、テスト計画書を作成

テストの実施

  • スケジュールに沿って、ユーザーテスト、機能テスト、負荷テストを含む各種機能の定期テストを実施する
  • バージョン更新後に回帰テストを行い、既存機能が壊れていないことを確認

問題の追跡と報告

  • 問題の再現手順と影響範囲を記録し、重要度を分類したうえでバグ追跡フローに乗せる
  • 問題の修正状況を完了まで追跡し、検証を行う
  • テスト結果を取りまとめ、テスト報告書を作成してプロダクト部門と開発部門に提出する

部門間の調整

  • プロダクト部門と開発部門が、問題の原因や仕様の解釈のずれを整理できるよう支援
  • 各部署（プロダクト部門、開発責任者を含む）とテストスケジュールや修正の優先順位を調整

応募条件

必須条件
  • 機能テスト（function test）の実務経験
  • バグトラッキングに精通していること：漏れなく記録し、優先度を付け、クローズまで追跡できる
  • ソフトウェア統合テストの経験
  • テスト計画書とテストレポートを独力で作成できる方
  • プロダクトや開発など異なる役割の人とコミュニケーションを取り、問題を明確に説明して対応を進められる
  • 台北・内湖のオフィスで月曜から金曜まで勤務できる
歓迎条件
  • Source Codeレベルでのプロダクトテスト経験（コードを読んで問題の原因特定を支援できる）
  • 普段から日本のゲームを遊んでいて、こうした製品の遊び方やユーザーの習慣に詳しい
  • テストケース管理やバグ管理システムの使用経験

このチャンスを選ぶ理由

テストの流れが体系的で、ただクリックするだけの作業ではありません

テストケースは自分で書き、テスト計画は自分で組み、テスト報告書も自分で提出します。1サイクルを終えたとき手元に残るのは、外でも語れるテスト文書とプロセスの経験であって、「たくさんのバージョンをテストした」だけではありません。

プロダクト部門・開発部門と直接連携

問題をフォームに入れて終わりではありません。プロダクトと開発の責任者に、原因と仕様の判断をはっきり説明し、優先順位を交渉していきます。テストリーダーや QA プロセス設計の道に進みたいなら、この経験は欠かせません。

給与レンジをはっきり記載

月給40,000～45,000台湾ドル、経験に応じて決定。応募して面接を終えるまで条件交渉の余地がわからない、ということはありません。

完全週休2日制（固定）

月曜〜金曜の勤務で、シフト制や交代勤務はありません。生活リズムを自分で整えられます。

Step1ne のコンサルタントが全面サポート

応募、面談の調整から入社後の定着まで、専任の担当者がフォローします。派遣期間中の労働契約は当社とあなたとの間で結ばれるため、労働条件について何か問題があれば直接コンサルタントに相談できます。

よくある質問

派遣の権利は正社員と同じですか？+

派遣期間中は Step1ne（德仁管理顧問有限公司）と正式な労働契約を結びます。賃金、労工保険・全民健康保険、労働者退職金の積立、年次有給休暇、残業代、労働災害補償などの権利は、すべて労働基準法および関連法令に基づいて取り扱われ、一般の被雇用者と同じです。解雇手当や退職についても労働基準法の規定が同様に適用されます。日々の業務は配属先のオフィスで行い、現場の上司が業務を割り振りますが、雇用主としての責任は Step1ne にあります。

月給 40–45K 台湾ドルとありますが、実際にはいくら受け取れますか？+

公開ページには総額のレンジを記載しています：月給 40,000 – 45,000 台湾ドル、経験に応じて決定。給与の内訳は、コンサルタントがお電話での初回面談でまとめてご説明しますので、その際に遠慮なく詳しく聞いてください。

職名に「シニア」とありますが、何年の経験があれば応募できますか？+

今回、配属先からは経験年数の条件が示されていないため、確認できていない数字をページに書くことはしません。見られるのは、あなたが実際に何をしてきたかです。機能テスト、Bug のクローズまでの追跡、ソフトウェア統合テスト、そしてテスト計画書とテスト報告書を自分で書けるかどうか。この4つを経験していれば応募する価値があります。経験年数については、コンサルタントがあなたに代わって配属先に確認します。

プログラミングができないとだめですか？+

必要ありません。必須条件は、機能テスト、統合テスト、課題追跡といった実務経験です。「Source Code レベルのプロダクトテスト経験」は歓迎条件なので、経験がある場合は、コードレベルでどんな問題を見つけたことがあるかを応募時に説明してください。

日本のゲームをプレイしていなくても応募できますか？+

はい、大丈夫です。「日本のゲームが好き」は歓迎条件であり、必須ではありません。ただ、この仕事は毎日ゲーム製品をテストするため、ゲームそのものに感覚がある人のほうがプレイヤーのつまずきやすい点に気づきやすい傾向があります。該当する方は応募時にぜひお書きください。

面談の流れは？AIと面談することになりますか？+

はい。一次面談はAIが担当し、テキストまたは音声で対話して、あなたの経験がこの求人の条件に合うかを確認します。通過後はコンサルタントが配属先との面接を手配します。AIとの一次面談の時間はご自身で選べるので、休みを取って合わせる必要はありません。

勤務時間は何時から何時まで？バージョンアップ時の残業はありますか？+

今回、派遣先から確認できたのは月〜金・週休2日という点だけで、具体的な勤務時間帯はまだ聞いていません。バージョン更新やリリースに合わせた時間調整が必要かどうかも説明がないため、確認できていないことはページに書きません。コンサルタントが初回面談の前に確認し、お伝えします。

この派遣の仕事はどれくらい続きますか？正社員になれる可能性はありますか？+

採用企業からは現時点で契約期間の長さや正社員登用の確約をいただいていないため、ページには記載していません。気になる場合は、面談時に私たちが代わりに直接確認し、採用企業の回答をそのままお伝えします。
