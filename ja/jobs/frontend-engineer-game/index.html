仕事内容

Web開発とデザインの忠実な再現

  • 運営部門と連携し、Web開発、コンテンツ更新と保守を行う
  • デザインカンプを忠実に実際のWebページとして再現

アニメーション効果とチーム連携

  • Webのアニメーション効果を制作し、ユーザーのインタラクション体験を向上
  • 運営部門、バックエンドチーム、デザイナーと連携・調整し、プロジェクトを円滑に推進する

応募条件

必須条件
  • フロントエンド開発経験3年以上
  • 実装力を示すポートフォリオの提出が必要（個人プロジェクト、受託案件、会社での成果物のいずれも可）
  • JavaScriptによるインタラクション実装に精通
  • CSS／SASS とレスポンシブ（RWD）開発に精通
  • Photoshopのデザインカンプを正確にコーディングして再現できる
  • クロスブラウザの互換性問題を解決できる
歓迎条件
  • Git によるバージョン管理と CI/CD の経験
  • AJAX とバックエンド API の連携に精通
  • フロントエンドフレームワークの経験（Vue、Pinia、Vuex。主にCDN利用）
  • AIとの協働が得意で、AI IDEを日常的に使っている方

このチャンスを選ぶ理由

作品がそのままリリースされ、達成感が目に見える

開発の成果は上場ゲーム企業グループの運営プロダクトに実際にリリースされます。あなたが書くコードの一行一行、作るアニメーションの一つひとつが多くのプレイヤーの目に触れ、使われます。作って終わりのプロジェクトではありません。

給与は実力に応じて決定、交渉の余地あり

給与は応相談です。コンサルタントがまずあなたの希望給与を伺い、採用企業と交渉して、画一的な給与テーブルではなく、あなたの技術力と経験が待遇にきちんと反映されるよう努めます。

派遣≠待遇の割引

派遣期間中は Step1ne があなたと正式な労働契約を結び、給与は Step1ne から支払われ、労工保険・全民健康保険にも加入します。年次有給休暇などの権利はすべて労働基準法に基づき、一般の被雇用者と同じです。

コンサルタントが最後まで一緒に交渉。履歴書を送って終わりではありません

Step1neのコンサルタントがまず秘密厳守で初回面談を行い、あなたの状況と条件を把握したうえで、合うと判断した場合にのみ企業へ推薦し面接を設定します。選考の過程では、あなたのために見極める人がついています。

よくある質問

この求人は人材紹介会社が探しているもの？背景にある企業はどこ？+

Step1neは德仁管理顧問有限公司のブランド（統一番号85046127）で、台北市政府発行の就業服務許可証（北市就服字第0363号）を保有し、登記住所は台北市内湖区康寧路三段54之7号3階です。エグゼクティブサーチ、正社員採用、人材派遣サービスに特化しています。

派遣の仕事は、正社員より待遇が悪くなりますか？+

いいえ。派遣期間中はStep1neがあなたと正式な労働契約を結び、給与、労働保険・健康保険、年次有給休暇などの権利はすべて労働基準法に基づいて扱われ、一般の雇用者と同じです。

応募にポートフォリオは必須ですか？+

はい。この求人ではデザインの再現度とアニメーション実装の力を特に重視しているため、実力を示すポートフォリオ（個人プロジェクト、受託案件、会社での制作物いずれも可）の提出が必要です。

面接はどのように進みますか？+

選考は3段階です。まず AI面接官・阿財（アツァイ）との一次面談、次にコンサルタントが守秘を前提にあなたの状況と条件を伺う面談を行い、適していると確認できれば正式な面接と条件交渉に進みます。最終的な採否は採用企業が決定します。
