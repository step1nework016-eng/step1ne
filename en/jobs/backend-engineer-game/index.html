.NET Engineer (Internal Enterprise Systems, AI-Assisted Development)

This role is in the IT development department of a publicly listed group, with 1 opening, working on the development, maintenance, and feature improvement of internal enterprise systems. The core focus is AI-assisted development, C#, .NET, MSSQL, and Git. You need hands-on experience using tools such as ChatGPT, GitHub Copilot, Cursor, Claude Code, or Codex to complete development work or solve problems.

Job description

System development and maintenance

  • Take part in developing, maintaining, and improving internal enterprise systems
  • Application and API development with C# and .NET/.NET Framework
  • Data queries, data processing, and performance tuning with Microsoft SQL Server (MSSQL)
  • Help analyze system issues and carry out debugging, testing, and issue resolution

Team collaboration and AI-assisted development

  • Participate in requirements discussions, technical design, code reviews, and team collaboration
  • Use AI-assisted development tools for coding, debugging, refactoring, and technical research to improve development efficiency and quality
  • Write and maintain necessary technical documentation, and continuously improve code quality, maintainability, and system stability

Skills you'll keep building after joining

  • Enterprise system development: a deep understanding of internal enterprise systems, database design, and system integration
  • Modernization: take part in optimizing existing systems, upgrading technology, and modern development practices
  • AI-assisted engineering: explore AI Coding Agents, development automation, and new software development processes
  • Software engineering practice: improve code quality through Code Review, CI/CD, and teamwork

Requirements

Required
  • 2+ years of software development experience
  • Well versed in C#, with hands-on development experience in .NET or .NET Framework
  • Well versed in MSSQL, able to write basic SQL, JOIN, and Stored Procedure statements and to work with databases
  • Basic understanding of object-oriented programming (OOP) and programming concepts
  • Foundational knowledge of Git version control and an understanding of basic branch management and team development workflows
  • Experience with AI-assisted software development, having used ChatGPT, GitHub Copilot, Cursor, Claude Code, Codex, or similar tools to complete real development work or troubleshoot technical issues
Preferred qualifications
  • Well versed in ASP.NET Core, ASP.NET MVC, or Web API development
  • Experience with RESTful API design or system integration
  • Knowledge of SQL performance tuning, index design, or database performance analysis
  • Experience with GitLab CI/CD, automated testing, or continuous integration
  • Exposure to Docker, Kubernetes, or cloud services such as AWS, GCP, or OCI
  • Experience using AI coding agents for feature development, code refactoring, or automated testing
  • Have proactively explored AI development tools, Agent Workflow, MCP, or other technologies that make software development more efficient
  • Tangible results from personal technical projects, GitHub work, or ongoing learning

Why this opportunity

AI-assisted development is part of everyday work in this role

The host organization treats AI-assisted development as a core priority, not a nice-to-have. If you already use AI tools to write code, debug, and refactor, this is a place where that will be put to real use.

Grow alongside others instead of just getting tasks done

The work includes code review and team collaboration. The hiring team hopes you will gradually grow into a software engineer who can design, develop, and solve problems independently.

Working conditions during the assignment follow the Labor Standards Act

During the staffing period, you sign a formal employment contract with Step1ne (德仁管理顧問有限公司). Wages, labor and health insurance, and annual leave follow the Labor Standards Act.

FAQ

Do dispatched workers get the same rights as full-time employees?+

During the staffing period, you sign a formal employment contract with Step1ne (德仁管理顧問有限公司). Your wages, labor and health insurance, labor pension contributions, annual leave, overtime pay, occupational injury compensation, and other rights all follow the Labor Standards Act and related regulations, the same as any other employee. Your day-to-day tasks are assigned by a manager at the host organization, but the employer's responsibilities rest with Step1ne. If you have questions about your working conditions, you can go directly to your consultant.

Why doesn't the page list the salary and work location?+

These two items aren't listed on this page yet. Your consultant will explain them during the first phone conversation.

Do I have to know AI development tools for this role?+

Yes. The requirements call for hands-on use of ChatGPT, GitHub Copilot, Cursor, Claude Code, Codex, or similar tools to help complete development work or solve technical problems. When you apply, you can simply describe what you have done with them.
